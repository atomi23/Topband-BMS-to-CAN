# 🔋 Topband / Victron Gateway V2.03 "Universal Master"

[Deutsch](README.md) · **English**

**One codebase for all boards. Max safety. Full control.**

An ESP32 gateway reads Topband BMS batteries (e.g. **EET, Power Queen, AmpereTime, Redodo**) over RS485 and presents their data as a native CAN-bus BMS to **Victron** systems (Cerbo GX, MultiPlus), **Deye**, or **SMA**.

**Current release:** [v2.03](https://github.com/atomi23/Topband-BMS-to-CAN/releases/tag/v2.03)
